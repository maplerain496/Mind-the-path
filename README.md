## 🎮 游戏简介

《句法拼图》是一款创新的语言学习游戏，通过"花园路径句"（Garden Path Sentence）来展示人类语言解析机制的奇妙之处。玩家需要在限定时间内将单词正确填入句法树槽位，体验语言理解中的"陷阱"。

### 什么是花园路径句？

花园路径句是一种特殊的句子结构，读者在阅读时会被误导到错误的句法解析路径，需要回溯重新解析。例如：

> **"The horse raced past the barn fell."**

初次阅读时，"raced"容易被误解为谓语动词，但实际上它是分词短语修饰"horse"。

## 🎯 游戏玩法

### 核心机制
1. **单词流出**：单词从屏幕顶部逐词流出
2. **拖拽放置**：将单词拖拽到正确的句法槽位
3. **验证解析**：点击「VERIFY」确认解析是否正确
4. **时间挑战**：在时间耗尽前完成尽可能多的关卡

### 句法槽位
- **NP** (Noun Phrase) - 名词短语
- **VP** (Verb Phrase) - 动词短语  
- **Participial** - 分词短语
- **PP** (Prepositional Phrase) - 介词短语

### 游戏按钮
| 按钮 | 功能 |
|------|------|
| **INITIALIZE** | 开始游戏 |
| **UNDO (-5s)** | 撤销上一步（扣除5秒） |
| **HINT** | 显示提示（扣除2秒） |
| **VERIFY** | 验证解析 |

## 🧪 心理语言学原理

### 最小附着原则
大脑倾向于用最少的句法节点来解析新词，这是导致花园路径效应的主要原因。

### 解析冲突
当遇到歧义结构时，大脑需要重新分析句子结构，这个过程称为"回溯"。
